# NEXORA 2027
### Where Innovation Meets Imagination

NEXORA 2027 is a responsive campus event website designed to showcase college events, schedules, and registration information in an interactive and visually engaging way.

## About the Project

The website is designed around the idea of bringing innovation, creativity, and campus activities together. It features a modern interface with a dark theme and interactive elements.

## Features

- Responsive navigation bar
- Featured and upcoming events
- Searchable and filterable event calendar
- Event details displayed in interactive modals
- Event schedule with timeline and tabs
- Registration interface
- Countdown timer
- IEM and UEM Kolkata branding

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server.
4. Explore the website in your browser.

## Note

This project is a demonstration website. Event details are sample content, and registration data is stored locally in the browser using Local Storage. No backend database is connected.
